# 循环的两层验证

仅在用户要求循环时使用；取消循环后移除回到开场的逻辑和相应验收项。

首尾调用同一个确定性构图。所有字幕、粒子、纹理、摄像机和背景都要回到同一状态。明确让第 0 帧和最后一帧共享边界，但仍检查最后几帧到开头的运动速度/方向。

首尾像素一致与运动流畅是两个条件；重复一张边界帧可能有一帧停顿。声音边界单独检查，不能只拼视频帧便声称整体无缝。

```sh
python3 "$SKILL_DIR/scripts/verify_video.py" final.mp4 \
  --timeline timeline.json --exact-loop \
  --source-first source-first.png --source-last source-last.png \
  --report validation.json
```

报告源 PNG 与最终解码画面两组比较，含最大通道差和不同像素数；精确相等要求任一非零都不通过。默认还执行完整解码。

有损编码上下文可能让相同源图在首尾解码略有差异。区分场景差异与编码漂移，再调整编码或复用独立边界编码帧；若交付无损版本，说明体积与播放兼容性的权衡并实测。

强制 I 帧、恒定 QP、把首帧再次送入编码器，都不保证精确相等。不要把一次有效的 FFmpeg 命令当通用保证。任何收尾处理都要保留帧数、帧率、色彩/像素格式和所需音轨，再检查最终产物。
