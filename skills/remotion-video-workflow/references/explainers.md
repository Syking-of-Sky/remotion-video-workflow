# 历史与原理图解

## 证据与叙事

明确观众最后能解释什么。历史以“问题 → 方法 → 局限 → 变化”组织，不必每幕重复总标题，留出原理的具体例子。

“最新”“这个月”“新架构”查当时的一手来源，记录日期、链接和支持的结论。找不到则标未核实，不凭模糊关键词猜名称。区分观测、标准理论、候选解释和教学示意；前沿宇宙假说不能写成已证实起源。

复杂过程用同一具体样例贯穿。程序手写的加噪/去噪要标“原理示意”，不冒充模型真实中间结果。详尽来源保存在研究文档，不挤满字幕。

## 公式与图形同源

每个公式节点有纯函数模型，视觉读取输出。参数变化同时驱动数值、箭头、粒子和高亮：

```ts
const step = (theta: number, rate: number) => ({
  theta, loss: (theta - 2) ** 2,
  gradient: 2 * (theta - 2), next: theta - rate * 2 * (theta - 2)
});
```

这个例子可同时画损失曲线、当前位置、梯度箭头与更新式。其他映射：权重控制连接强度，卷积窗口共享索引，softmax 条高来自真实概率。公式写注意力时，粒子不能只是无意义旋转。

推导按定义量、代入、运算、结果展开，保持上一状态可识别。复杂结构先总览再逐项解释；小型注意力矩阵也要维度正确。

验证有意义的算例与不变量，如概率和、梯度符号、维度、边界和参数变化响应。定性图不冒称物理模拟，也不为了测试而捏造科学约束。

## 密度与阅读

增加密度可缩短闲置、增加镜头内的有意义变化、减少重复标题、把长解释移入旁白。最密一屏必须抽帧。主体、短说明、公式、字幕有安全区；实际可读性比段落数量重要。

旁白按真实声音长度回填场景和字幕，不为凑时长切断解释。术语先正确再口语化，一句引入多个概念时拆成两步。
